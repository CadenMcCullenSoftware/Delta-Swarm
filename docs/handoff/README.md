# Swarm Pilot Handoff Bundle

Draft buyer-facing materials for the `v1.0.1` source release. Confirm all
commercial terms and buyer-specific scope in a signed statement of work before
making an offer or beginning custom work.

- [Buyer overview](./buyer-overview.md) — capabilities, limitations, setup,
  licensing, and access.
- [Quickstart and verification](./quickstart.md) — reproducible install,
  checks, and smoke test.
- [Pilot offer sheet](./offer-sheet.md) — draft $149, $499, and $1,500 options
  with fields for agreed scope and payment terms.
- [Acceptance checklist](./acceptance-checklist.md) — sign-off and verification
  record.
