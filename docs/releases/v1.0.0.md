## Included capabilities

- Local workflow orchestration across coordinator, planner, worker, and
  reviewer agents.
- Dependency-ordered task execution through the Python API and CLI.
- Explicit approval gates and separate compliance and correctness records;
  correctness remains a human commander's decision.
- Evidence records, governance checks, JSON schemas, and a lightweight
  governance configuration loader.
- Governance and terminology documentation.

## Scope and known limitations

This is a local Python package. Workflow state is in memory, and task commands
run with the invoking user's host privileges. Separate CLI invocations do not
share state; multi-step workflows use the Python API in one process or the
NLP REPL. The package does not supply sandboxing, VM/container isolation,
persistent CLI state, or custom adapters. Those items need separate scope and
verification.
