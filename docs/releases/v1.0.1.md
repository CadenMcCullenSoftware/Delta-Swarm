## Scope and limitations

Swarm is a local Python package. Workflow state is in memory, and task
commands run with the invoking user's host privileges. The package does not
provide sandboxing, VM/container isolation, network isolation, resource
limits, or persistent CLI state. See the [buyer overview](../handoff/buyer-overview.md)
and [technical documentation](../swarm.md) before use.
